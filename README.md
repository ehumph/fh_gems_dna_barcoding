# 💎 GEMs OTTR Template

The goal of this template is to make it easier to make consistently structured modules for the Genomics Education Modules (GEMs) Program, a collaborative project between Fred Hutch Cancer Center and community college faculty partners.

Our team focuses specifically on [genomic data science](https://www.genome.gov/about-genomics/fact-sheets/Genomic-Data-Science), an interdisciplinary field that combines both biology and computational skills. Here, you will be able to find links to our modules to use in the classroom or workplace.

Find out more about us and download resources on our website. GEMs is funded by the National Human Genome Research Institute [1R25HG013489](https://reporter.nih.gov/search/SjWuEKrSVEGVaHvRb9L-vg/project-details/10854368).

🦦 This repository is based on a template from [ottrproject.org](https://www.ottrproject.org/getting_started.html). 

## Content pages

| File | What to change |
| --- | --- |
| `index.qmd` | Homepage; embeds subpages automatically |
| `_description.qmd` | subpage with module description |
| `_learning_objectives.qmd` | subpage with learning objectives |
| `_timing.qmd` | subpage with timing, prereqs |
| `_reqd_materials.qmd` | subpage with required materials |
| `_evaluation.qmd` | subpage with links to surveys |
| `instructor_materials.qmd` | Instructor-facing materials |
| `adapt_materials.qmd` | "Adapting this Activity" guidance |
